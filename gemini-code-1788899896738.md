# SnapGrab Monetization & Compliance Roadmap

This document outlines the step-by-step implementation plan for monetizing SnapGrab with clean, non-intrusive ad placements while ensuring AdSense approval.

---

## Phase 1: On-Site UX & Ad Layout Setup
- [ ] Implement the dynamic loading-state ad unit inside the video processing container.
- [ ] Add the native article recommendation widget container below the FAQ section.
- [ ] Verify 16px+ padding between action buttons (`#download-btn`, `#paste-btn`) and ad units to prevent accidental clicks.

---

## Phase 2: Content & Policy Requirements
- [ ] Create legal trust pages (`/privacy`, `/terms`, `/about`, `/contact`).
- [ ] Link all trust pages clearly in the website footer.
- [ ] Publish 10–15 informational guides/blog posts (800+ words each) to pass AdSense's "Value Content" review.
- [ ] Expand homepage FAQ text to provide sufficient text context for ad crawlers.

---

## Phase 3: Network Application & Ads Integration
- [ ] Submit `https://snapgrab-seven.vercel.app` to **Google AdSense**.
- [ ] Add the global AdSense script inside the `<head>` section of `index.html`.
- [ ] Create and upload a valid `ads.txt` file to the root directory (`/public/ads.txt`).
- [ ] Apply for native networks (e.g., Taboola or Outbrain) after reaching traffic thresholds.

---

## Phase 4: SEO & Revenue Scaling
- [ ] Set up programmatic landing pages (`/download-instagram-reels`, `/tiktok-no-watermark`).
- [ ] Optimize page load speed (aim for < 2s response time) for high Core Web Vitals.
- [ ] Track ad viewability and click-through rates (CTR) via Google Analytics.
